# Proposal

## Why

Currently, the setup portal web interface exposes no mechanism to remotely turn the ATX power supply on or force-cut power, and the optional motherboard graceful shutdown controls are housed inside the System configuration tab alongside firmware updates and factory reset. Adding a dedicated Power tab provides an intuitive control dashboard to inspect live power telemetry, power on the machine, force cut power safely with a confirmation guard, and trigger clean OS shutdowns via motherboard button pulses.

## What Changes

- Add a dedicated **Power** tab to the web UI positioned between the Network and System tabs: `[Bluetooth] [Network] [Power] [System]`.
- Move the motherboard power button (graceful shutdown) configuration toggle and action button entirely from the System tab to the new Power tab.
- Add an ATX power supply control card to the Power tab with:
  - **Power On** button: active when the system is in `STATE_OFF`, initiating the power-on sequence via `PS_ON#`.
  - **Force Cut Power** button: active when in `STATE_ON` or `STATE_BOOTING`, requiring explicit confirmation through a modal dialog to prevent accidental filesystem corruption.
- Add authenticated HTTP POST endpoints:
  - `POST /api/power/on`: requests machine power-on.
  - `POST /api/power/off`: requests immediate power cut.
- Label the motherboard button pulse action as **"Shut Down OS"** (active only when the feature is enabled and the board is in `STATE_ON`).
- Maintain thread-safe, monotonic execution by queuing power requests as flags serviced on the main Arduino loop.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `setup-portal`: Updates portal tab navigation to include the Power tab, moves power button controls out of the System tab, adds ATX power controls with a confirmation modal, and exposes the `POST /api/power/on` and `POST /api/power/off` endpoints.
- `power-control`: Adds programmatic power-on and programmatic force-cut power requests initiated via the web portal API.

## Impact

- **Web UI (`app/index.html`)**: Tab bar updated to 4 tabs; new Power panel added; graceful shutdown card moved from System tab; force-power-off confirmation modal added; JavaScript updated to wire power on, power off, and modal interactions.
- **Backend (`src/portal.cpp`, `include/portal.h`)**: New routes `/api/power/on` and `/api/power/off` with authentication and state validation.
- **Main State Machine (`src/main.cpp`)**: Added `requestPowerOn()` and `requestPowerOff()` flags dispatched in `normalLoop()`.
- **Precompiled HTML Header (`include/portal_html.h`)**: Regenerated by `scripts/build_html.py` during compilation.
